# Non-Access Stratum (NAS)

1. Implementation of 3GPP TS 24.501 Release 18.

2. Supports NAS encoding/decoding of messages.

3. This module supports integrity & Ciphering algorithms

4. Currently the NAS module is used by the AMF, SMF and gNBSim components.
